# Contributing / 貢献について

- Issue・Pull Request は歓迎します。大きな変更は先に Issue で相談してください。
- 送る前に: `npm ci`、`npm test`、`npm run build:web` が通ること（Node.js 18 以上）。テストを足したら `package.json` の `test` にも足してください。
- API キー・個人のパス・メールアドレスなどをコミットしないでください。実データ（`%APPDATA%\hex-memo`）は入れないでください。
- 送られた変更は MIT ライセンス（LICENSE）で公開されることに同意したものとします。

Issues and pull requests are welcome. Please make sure `npm ci`, `npm test` and `npm run build:web` pass before sending (Node.js 18+), never commit secrets, personal paths or your own memo data, and note that contributions are licensed under MIT.
